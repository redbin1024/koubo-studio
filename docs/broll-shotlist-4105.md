# 4105 全功能版 · B-roll 拍摄清单

目标：不改口播、不重剪，只补 6–8 段真实细节，让画面从“同一机位”变成“人物 + 具体对象”。

## 素材规格

- 竖屏 9:16，1080×1920 或更高；
- 每段 3–6 秒，成片只用 1.5–2.5 秒；
- 固定机位/缓慢推近，不要手持抖动；
- 默认不需要原声（B-roll 轨会静音）；
- 不拍客户正脸（除非有书面授权）；不拍其他品牌 Logo。

## 剪辑规则

- 只在关键词附近切，切完 1.5–2.5 秒回人物；
- 结尾 CTA 卡出现时，B-roll 在底层做环境，不要和 CTA 争主体；
- 同类镜头只用一次，不堆空镜；
- 没有素材的时窗不要硬填，宁可保留人物。

## 加进去之后

```jsonc
"broll": {
  "enabled": true,
  "items": [
    {"cue": 4, "keyword": "营养餐", "source": "broll/broll-02-food.mp4",
     "in": 0.3, "dur": 1.5}
  ]
}
```

```bash
koubo draft 4105-全功能版 --name 4105-全功能版-Broll
```

B-roll 轨只进草稿；mp4 预览不含。
