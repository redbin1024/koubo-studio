# 证据登记表

原则：**没有来源的数字，不写进规则或默认值。** 每个参数至少标一个等级。

| 等级 | 含义 |
| --- | --- |
| L1 | 本机逐帧/逐像素/逐文件实测，可复现 |
| L2 | 从剪映 UI 或官方资源直接读到 |
| L3 | 二手教程/社区结论，未独立复核 |
| L4 | 本项目策略（可以改，但必须知道它不是通用真理） |

## 使用规则

1. 引用 L3 参数时，必须写“待目视确认”。
2. 改默认值前，先补一条 L1 证据或明确标为 L4 策略。
3. 不要把“API 接受了”当成“效果正确”。
