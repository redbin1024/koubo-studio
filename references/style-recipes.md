# 风格语汇与音效映射

这套包装拆开就是六个动作。想换风格就逐个换，不要一次全换 —— 换完抽帧比对，
比在脑子里推演靠谱得多。

## 一、正片全程满屏真人

除卡段外，人物不缩、不垫模糊底。这条最容易被过度设计：一上来就「人缩到左边 + 右侧留白
放动画」会让整条片子失去口播的亲近感。参考片只有一个结构切换，其余时间都是原始画面。

例外是卡段：整屏换成「模糊放大的真人做底」，那一段不再满屏。

## 二、字幕 = 白粗体 + 黑硬描边 + 明显投影

- 字号按最长行**实测字宽**自适应：从 `size_cap` 往下试，试到最宽一行塞得进 `max_width`。
  不要按「`max_width` / 字数」估 —— 同字号下不同字体字身宽能差 20%+，按字数估会在
  宽字身上直接把行顶出画面。`max_width` 就取「画布宽 − 2 × `margin_lr`」。
- 位置贴人物腰部偏下（`block 底 ≈ 0.90H`），**不要居中**。居中会压住胸口和手部动作，
  而且和人物脸部抢视觉重心。
- 描边要硬、投影要明显，不要柔和阴影 —— 手机小屏上柔阴影等于没有。但**两项别同时下狠手**：
  `outline` 取字号 5% 上下（104px 字 ≈ 6px）、`shadow` 取 3~4%。一起加厚，描边会把笔画
  吃进去、投影再把边缘糊开，字看着就脏。
- **别用斜体中文。** 中文没有真斜体，程序化倾斜的笔画是歪的，小屏上就是廉价综艺感。

## 三、双强调色

正向词走黄（`accent`），反差词/数字走粉（`contrast`）。颜色从参考片量，不要凭印象选。
在 SRT 里用 `[[词]]` `((词))` 标，别在 config 里维护行号映射 —— 改字幕时两边会失步。

## 四、首句 hook

参考片开场是「超大字砸出 → 缩回常规字号」。ASS 实现：

```
{\fad(50,0)\fscx330\fscy330\bord2.5\t(0,600,2.6,\fscx100\fscy100\bord10)}
```

两个坑：
- **`\t` 的 accel 方向反直觉**。`2.6` 才是「前段几乎保持超大、末尾快速收回」；
  写 `0.35` 会在开头 0.15s 就把缩放走完，大字根本看不见。参数别推公式，渲帧比。
- **描边要跟着字号一起收**。330% 的大字配 10px 描边会糊成一团黑边，所以起手 2.5px。

## 五、单段信息卡（模糊底 + 白边灰面圆角卡 + 右下圆角画中画）

图层顺序固定为 **底 → 卡 → 画中画 → 标题/条目 → 图标**。
参考片第二行的图标明显盖在画中画上，顺序错了会看起来像贴纸浮着。

- 模糊底：ffmpeg 预算出 `work/blurred.mp4`（放大 → gblur → 压暗），
  逐帧只读不算。整屏高斯模糊放在逐帧循环里根本跑不动。
- 条目逐行横向擦出，图标延迟 0.10s 弹入（`scale 0.55 → 1.0`）。
- 卡段**不烧字幕**：那一屏的卡片就是放大的字幕，重复会打架。

## 六、结尾发光大字 + 快速淡黑

金色发光大字亮 0.8–1.2s，亮完即收，**不做常驻字标、不做片尾卡**。
收尾用 0.4s 快速淡黑（参考片就是这样，不是加了黑场卡）。

发光字实现要拆三层，画在一层里会糊：

1. `mask` = 字 + 描边（`stroke_width` 放大）
2. `glyph` = 只要字身（无描边）
3. `edge = mask - glyph` → 深色描边层；渐变只 `putalpha(glyph)`

**渐变必须铺满整幅高度。** 只在字附近的行区间画渐变，落在区间外的像素 alpha 为 0，
字会被横着切掉一半。

## 音效 cue 表

`make_sfx.py` 的 `CUES`，`config.sfx.events[].cue` 就是查这张表：

| cue | 素材（峰值 dBFS） | 用在哪 |
| --- | --- | --- |
| `hook` | impact-bass-2 (−14) | 开场大字砸出 |
| `cut` | impact-bass-2 (−15) + whoosh-cinematic (−17) | **结构切换**：切入卡段 |
| `return` | impact-bass-2 (−16) | 切回满屏真人 |
| `wipe` | whoosh-short (−22) | 句间快切、元素横移 |
| `row` | pop (−19) | 条目逐行擦出 |
| `tick` | click-soft (−24) | 轻落点 |
| `reveal` | chime (−19) | 否定转肯定 |
| `ping` | ping (−21) | 关键数据点 |
| `shine` | sparkle (−20) + whoosh-cinematic (−18) | 结尾发光字 |
| `end` | click-soft (−26) | 收尾轻点 |

规矩：

- **结构重音默认 `impact-bass-2`，不要 `impact-bass-1`。** 后者是干砸，
  整条片子连砸几次观感很廉价；前者带一小段预示性 swell，落点更靠前。
- **重音只留给真正的结构切点**，其余落点交给 pop / click / chime / ping。
  一条片子里重音超过 4 次就已经在「一直响」了。
- 长铺垫素材（`riser`、`whoosh-cinematic`）**对齐尾巴**：起点 = 落点 − 时长。
- 其余素材**按峰值对齐**：真实采样有 25–420ms 起音，把素材起点放在画面点上会晚一截。
- 低频撞击做 60Hz 一阶高通，否则手机小喇叭放不出来。
